# Phylogenetic Nearest Neighbours analysis

This repository includes analysis of the phyloKNN model (https://github.com/alrichardbollans/phylokNN) against other conventional and less
conventional approaches. Description and analysis of these
methods are described
in: [The persistent advantage of model-based phylogenetic methods for single-trait prediction](https://doi.org/10.1111/2041-210x.70258).
